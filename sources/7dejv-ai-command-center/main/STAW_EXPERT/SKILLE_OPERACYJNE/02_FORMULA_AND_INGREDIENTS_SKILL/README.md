# 02_FORMULA_AND_INGREDIENTS_SKILL

Skill odpowiada za porządkowanie składów roboczych, substancji, mieszanek i założeń działania produktów STAW EXPERT. Jego zadaniem jest zebrać informacje o składnikach, wskazać potencjalne funkcje, ryzyka, pytania do laboratorium i braki danych.

## Kiedy używać

Używaj tego skillu, gdy pojawia się pomysł na preparat, mieszankę mineralną, środek do poprawy jakości wody, produkt antyglonowy albo produkt wspierający kondycję ryb. Skill powinien działać przed opisem marketingowym i przed grafikami, żeby nie tworzyć obietnic bez podstaw.

## Dane wejściowe

- nazwa robocza produktu
- lista składników lub substancji
- planowana forma produktu
- planowane zastosowanie
- problem, który produkt ma rozwiązać
- robocze dawkowanie, jeżeli istnieje
- grupa docelowa
- ograniczenia bezpieczeństwa
- pytania do sprawdzenia

## Wynik

Skill powinien przygotować kartę składników: funkcja składnika, możliwe zalety, ryzyka, braki danych, pytania do laboratorium i oznaczenie elementów wymagających weryfikacji. Wynik ma być materiałem roboczym do rozmowy ze specjalistą, nie gotową recepturą dopuszczoną do sprzedaży.

## Zasady jakości

Skill nie zatwierdza produktów i nie udaje laboratorium. Każde dawkowanie, skład, deklaracja działania i bezpieczeństwo muszą być oznaczone jako robocze, dopóki nie zostaną zweryfikowane. Szczególnie ostrożnie należy traktować produkty wpływające na ryby, organizmy wodne i parametry wody.
