# 01_PRODUCT_RESEARCH_SKILL

Skill odpowiada za badanie sensu produktu przed rozpoczęciem pracy nad opisami, grafikami, składami i sprzedażą. Jego zadaniem jest sprawdzić, czy produkt rozwiązuje realny problem właścicieli oczek wodnych, kto jest odbiorcą, jaka jest konkurencja i jakie dane są jeszcze potrzebne.

## Kiedy używać

Używaj tego skillu na początku pracy nad każdym nowym produktem lub linią produktową. Powinien być uruchamiany zanim powstaną etykiety, grafiki i opisy sprzedażowe, ponieważ najpierw trzeba zrozumieć problem klienta, rynek i ryzyka.

## Dane wejściowe

- nazwa robocza produktu
- problem, który produkt ma rozwiązać
- grupa docelowa
- typ oczka wodnego lub stawu
- sezon użycia
- konkurencyjne produkty, jeżeli są znane
- wstępna cena lub pojemność
- założenia działania produktu
- pytania, na które trzeba znaleźć odpowiedź

## Wynik

Skill powinien przygotować raport badawczy: opis problemu, profil klienta, analizę konkurencji, potencjalne przewagi, ryzyka, braki danych i listę kolejnych działań. Wynik powinien jasno wskazywać, czy produkt ma sens rozwijać dalej, czy wymaga jeszcze mocnego dopracowania.

## Zasady jakości

Nie wolno zakładać, że produkt jest dobry tylko dlatego, że brzmi ciekawie. Skill ma szukać słabych punktów, brakujących danych i ryzyk. Wnioski powinny być praktyczne, a nie ogólne.
