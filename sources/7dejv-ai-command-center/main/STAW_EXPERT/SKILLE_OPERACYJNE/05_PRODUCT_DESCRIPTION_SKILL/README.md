# 05_PRODUCT_DESCRIPTION_SKILL

Skill odpowiada za tworzenie opisów produktów STAW EXPERT do sklepu, marketplace, SEO i materiałów sprzedażowych. Jego zadaniem jest zamienić dane produktu w prosty, przekonujący i bezpieczny komunikat dla klienta.

## Kiedy używać

Używaj tego skillu dopiero wtedy, gdy istnieją podstawowe dane produktu: przeznaczenie, grupa docelowa, problem klienta, forma produktu, pojemność, sposób użycia i ograniczenia. Skill nie powinien wymyślać składu, dawkowania ani obietnic działania bez danych źródłowych.

## Dane wejściowe

- nazwa produktu
- opis problemu klienta
- przeznaczenie produktu
- forma i pojemność
- główne korzyści
- sposób użycia
- ograniczenia i ostrzeżenia
- dane z etykiety
- kanał publikacji: PrestaShop, Allegro, Erli, blog, social media
- styl komunikacji

## Wynik

Skill powinien przygotować opis główny, krótki opis, tytuły, meta title, meta description, FAQ, opis Allegro, opis Erli i wersję skróconą do grafiki. Wynik powinien być praktyczny, sprzedażowy i zgodny z danymi produktu.

## Zasady jakości

Opis ma sprzedawać, ale nie może obiecywać więcej niż produkt realnie potwierdza. W przypadku preparatów do wody i ryb należy unikać deklaracji leczniczych, pewnych gwarancji efektu i niezweryfikowanych twierdzeń. Jeżeli dane są robocze, opis musi to respektować.
