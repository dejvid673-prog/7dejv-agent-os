# 03_LEGAL_CERTIFICATION_SKILL

Skill odpowiada za wstępną kontrolę ryzyk prawnych, certyfikacyjnych i komunikacyjnych dla produktów STAW EXPERT. Jego zadaniem jest wskazać, które deklaracje, składniki, zastosowania lub opisy mogą wymagać dodatkowej weryfikacji przed sprzedażą.

## Kiedy używać

Używaj tego skillu zawsze przed przygotowaniem etykiety, opisu sprzedażowego, oferty marketplace lub materiałów reklamowych. Jest szczególnie ważny przy preparatach do wody, produktach wpływających na organizmy wodne, środkach antyglonowych i produktach sugerujących działanie zdrowotne dla ryb.

## Dane wejściowe

- nazwa produktu
- skład roboczy
- przeznaczenie produktu
- planowane deklaracje marketingowe
- sposób użycia
- dawkowanie robocze
- grupa docelowa
- kraj lub rynek sprzedaży
- forma sprzedaży: sklep, marketplace, hurt, B2B

## Wynik

Skill powinien przygotować listę ryzyk, pytań do specjalisty, elementów wymagających dokumentów, potencjalnie problematycznych sformułowań i bezpieczniejszych wersji komunikatów. Wynik ma pomagać ograniczać błędy, ale nie zastępuje porady prawnej ani formalnej oceny zgodności.

## Zasady jakości

Skill ma być ostrożny. Jeżeli produkt może zahaczać o biocyd, produkt leczniczy, paszę, dodatek, środek chemiczny lub preparat wpływający na środowisko wodne, należy to wyraźnie oznaczyć jako temat do sprawdzenia. Nie wolno tworzyć fałszywego poczucia, że produkt jest legalny tylko dlatego, że opis brzmi bezpiecznie.
