# SKILLE_OPERACYJNE

Folder zbiera najważniejsze skille operacyjne dla projektu STAW EXPERT. Te skille nie służą do samych grafik, tylko do prowadzenia całego przedsięwzięcia: badań produktu, składów roboczych, prawa, kontaktu z laboratoriami, opisów sprzedażowych i kontroli jakości.

Ich zadaniem jest pilnowanie procesu od pomysłu do materiału gotowego do dalszej weryfikacji lub sprzedaży. Dzięki nim praca nie zaczyna się od przypadkowej grafiki albo opisu, tylko od danych, ryzyk, dokumentacji i logicznej kolejności.

Podstawowy proces pracy:

1. PRODUCT_RESEARCH_SKILL — sprawdza sens produktu i rynek.
2. FORMULA_AND_INGREDIENTS_SKILL — porządkuje skład roboczy i składniki.
3. LEGAL_CERTIFICATION_SKILL — oznacza ryzyka prawne i certyfikacyjne.
4. LABORATORY_CONTACT_SKILL — przygotowuje materiały do kontaktu z laboratorium.
5. PRODUCT_DESCRIPTION_SKILL — tworzy opisy sprzedażowe i SEO.
6. QA_AUDIT_SKILL — kontroluje jakość, spójność i braki.

Zasada nadrzędna: wszystkie składy, dawkowania, deklaracje działania i obietnice marketingowe są robocze, dopóki nie zostaną sprawdzone przez odpowiednie laboratorium, specjalistę lub osobę odpowiedzialną za zgodność prawną.
