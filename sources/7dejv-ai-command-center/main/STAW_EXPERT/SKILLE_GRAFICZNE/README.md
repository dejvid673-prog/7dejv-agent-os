# SKILLE_GRAFICZNE

Folder zbiera cztery główne skille graficzne dla projektu STAW EXPERT. Ich celem jest uporządkowanie pracy nad etykietami, grafikami produktowymi, grafikami marketplace oraz grafikami edukacyjnymi.

Każdy skill opisuje, do czego służy, jakie dane wejściowe powinien otrzymać i jaki wynik powinien przygotować. Dzięki temu można łatwiej pracować z ChatGPT, Codexem lub innymi narzędziami AI bez każdorazowego tłumaczenia zasad od początku.

Zasada nadrzędna: etykieta i dane produktu są źródłem prawdy. Grafiki sprzedażowe, marketplace i edukacyjne powinny wynikać z ustalonych informacji o produkcie, a nie wymyślać nowych obietnic bez weryfikacji.
