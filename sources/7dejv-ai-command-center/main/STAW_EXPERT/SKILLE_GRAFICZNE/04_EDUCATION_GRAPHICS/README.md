# 04_EDUCATION_GRAPHICS

Skill odpowiada za grafiki edukacyjne dla bazy wiedzy STAW EXPERT. Jego zadaniem jest tłumaczenie problemów oczek wodnych prostym językiem wizualnym: glony, mętna woda, pH, filtracja, lampa UV, choroby ryb, dawkowanie preparatów i typowe błędy właścicieli.

## Kiedy używać

Używaj tego skillu, gdy trzeba przygotować grafikę do artykułu, poradnika, FAQ, wpisu społecznościowego lub instrukcji dla klienta. Skill nadaje się do tworzenia schematów, infografik, map problemów, prostych diagramów oraz grafik krok po kroku.

## Dane wejściowe

- temat edukacyjny
- problem klienta
- poziom trudności odbiorcy
- miejsce publikacji
- najważniejsze fakty do pokazania
- produkt powiązany, jeżeli istnieje
- format grafiki
- styl: prosty, techniczny, premium, poradnikowy lub katalogowy

## Wynik

Skill powinien przygotować koncepcję grafiki, opis układu, prompty graficzne, teksty do użycia na grafice oraz checklistę kontroli. Wynik powinien pomagać klientowi zrozumieć problem, a nie tylko wyglądać efektownie.

## Zasady jakości

Grafika edukacyjna ma wyjaśniać, a nie straszyć i nie udawać diagnozy specjalistycznej. Treść powinna być krótka, praktyczna i zgodna z bazą wiedzy. Jeżeli temat dotyczy zdrowia ryb, prawa lub dawkowania preparatu, należy oznaczyć elementy wymagające weryfikacji przez specjalistę.
