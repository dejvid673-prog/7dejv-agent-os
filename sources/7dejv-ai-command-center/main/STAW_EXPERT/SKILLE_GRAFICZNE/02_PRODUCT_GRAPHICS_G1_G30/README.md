# 02_PRODUCT_GRAPHICS_G1_G30

Skill odpowiada za tworzenie pełnych pakietów grafik produktowych w systemie G1-G30. Jego celem jest uporządkowanie wszystkich typów grafik: od głównego zdjęcia produktu, przez packshoty, sceny zastosowania, infografiki, grafiki problem/rozwiązanie, aż po banery i grafiki premium.

## Kiedy używać

Używaj tego skillu, gdy produkt ma otrzymać kompletny zestaw grafik do sklepu, marketplace, social media lub prezentacji. Skill nadaje się szczególnie do produktów typu: preparat na glony, środek do poprawy jakości wody, wsparcie dla ryb, lampa UV, filtracja, bakterie lub minerały.

## Dane wejściowe

- nazwa produktu
- typ opakowania
- pojemność lub waga
- gotowa lub robocza etykieta
- opis działania produktu
- główny problem klienta
- grupa docelowa
- miejsce użycia produktu
- styl graficzny
- format grafik: 1:1, 4:5, 16:9, baner, plandeka
- marketplace lub kanał użycia

## Zakres G1-G30

- G1: główna grafika produktu
- G2: czysty packshot
- G3: produkt w scenerii oczka wodnego
- G4: etykieta lub wizualizacja etykiety
- G5: problem klienta
- G6: rozwiązanie problemu
- G7: dawkowanie lub sposób użycia
- G8: efekt przed i po
- G9: grafika Allegro
- G10: grafika PrestaShop
- G11-G18: grafiki sprzedażowe i korzyści
- G19-G24: grafiki marketplace i porównawcze
- G25-G30: plandeki, zestawy, grafiki premium i warianty reklamowe

## Wynik

Skill powinien przygotować listę grafik do wykonania, prompty graficzne, opis celu każdej grafiki, wymagany format, elementy widoczne na grafice oraz checklistę kontroli. Jeżeli użytkownik wybierze tryb pełny, skill powinien zaproponować logiczną kolejność pracy: etykieta, packshot, grafiki problemu, grafiki rozwiązania, marketplace, plandeka i audyt.

## Zasady jakości

Grafiki muszą być spójne z etykietą i danymi produktu. Nie należy tworzyć efektów, obietnic ani składników, których nie ma w dokumentacji. Każda grafika powinna mieć jasny cel: sprzedaż, wyjaśnienie, edukacja, porównanie albo budowanie zaufania.
