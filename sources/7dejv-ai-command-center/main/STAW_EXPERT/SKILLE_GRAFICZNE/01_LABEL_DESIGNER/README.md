# 01_LABEL_DESIGNER

Skill odpowiada za przygotowywanie koncepcji etykiet produktów STAW EXPERT. Jego zadaniem jest pilnowanie czytelności, hierarchii informacji, stylu marki, pojemności, przeznaczenia produktu, ostrzeżeń, dawkowania oraz podstawowych zasad projektowania pod druk.

## Kiedy używać

Używaj tego skillu zawsze, gdy powstaje nowy produkt, nowa linia produktowa albo nowa wersja opakowania. Etykieta powinna być jednym z pierwszych etapów pracy, ponieważ później staje się źródłem prawdy dla grafik produktowych, marketplace i opisów sprzedażowych.

## Dane wejściowe

- nazwa produktu
- typ produktu
- pojemność lub waga
- przeznaczenie
- grupa docelowa
- główny problem klienta
- podstawowe działanie produktu
- skład roboczy, jeżeli istnieje
- dawkowanie robocze, jeżeli istnieje
- ostrzeżenia i ograniczenia
- styl graficzny marki

## Wynik

Skill powinien przygotować układ etykiety, listę tekstów na etykietę, propozycję hierarchii informacji oraz checklistę kontroli. Jeżeli dane są robocze, powinien wyraźnie oznaczyć elementy wymagające weryfikacji przez laboratorium, specjalistę lub osobę odpowiedzialną za zgodność prawną.

## Zasady jakości

Etykieta nie może być przeładowana tekstem. Najważniejsze informacje muszą być widoczne szybko: nazwa, zastosowanie, pojemność, główna korzyść i sposób użycia. Nie wolno tworzyć obietnic leczniczych ani technicznych bez potwierdzenia w dokumentacji.
