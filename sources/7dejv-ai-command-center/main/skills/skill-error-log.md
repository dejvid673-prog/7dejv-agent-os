# Skill: Error Log

## Cel

Katalogowanie błędów tak, żeby nie zaczynać pracy od zera po każdym problemie.

## Kiedy używać

Używać, gdy:

- pojawi się błąd modułu,
- Codex popełni błąd,
- HTML/CSS/JS się rozsypie,
- hook nie działa,
- panel się nie wyświetla,
- wystąpi problem z repo,
- trzeba zapisać przyczynę i naprawę.

## Dane wejściowe

- data,
- projekt,
- objaw,
- błąd,
- przyczyna,
- naprawa,
- status.

## Procedura

1. Otwórz `reports/error-log.md`.
2. Dodaj nowy wpis.
3. Opisz objaw prostym językiem.
4. Wypisz prawdopodobną przyczynę.
5. Dodaj wykonaną lub planowaną naprawę.
6. Dodaj status.
7. Jeśli błąd jest większy, utwórz Issue.

## Format wpisu

```text
Data:
Projekt:
Błąd:
Objaw:
Przyczyna:
Naprawa:
Status:
Link do pliku / issue:
```

## Wynik końcowy

- błąd zapisany,
- znana przyczyna lub hipoteza,
- znany status,
- możliwość powrotu do tematu bez szukania w rozmowach.
