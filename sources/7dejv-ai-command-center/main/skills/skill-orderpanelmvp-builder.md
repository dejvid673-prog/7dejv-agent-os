# Skill: orderpanelmvp Builder

## Cel

Budowa lub poprawa modułu `orderpanelmvp`, czyli lekkiego panelu zamówień do pakowania i kontroli w Back Office PrestaShop.

## Kiedy używać

Używać przy zadaniach dotyczących:

- listy zamówień,
- panelu pakowania,
- widoku Back Office,
- poprawy HTML/CSS/JS,
- UX osoby pakującej,
- statusów logistycznych,
- przejścia do modułu DPD.

## Dane wejściowe

- wersja PrestaShop,
- cel panelu,
- wymagane kolumny,
- statusy zamówień,
- akcje użytkownika,
- istniejący kod lub prototyp.

## Procedura

1. Przeczytaj wymagania modułu.
2. Sprawdź granicę między `orderpanelmvp` i `dpdshipmvp`.
3. Zaprojektuj minimalny widok MVP.
4. Sprawdź, jakie dane są potrzebne osobie pakującej.
5. Zaprojektuj prosty HTML/CSS/JS.
6. Nie dodawaj logiki API DPD.
7. Wykonaj audyt UI.
8. Przygotuj checklistę testów.

## Wynik końcowy

- czytelny widok listy zamówień,
- opis funkcji,
- lista plików,
- raport audytu,
- plan dalszego rozwoju.

## Czego unikać

- wywoływania API DPD,
- generowania etykiet,
- dodawania hooków frontowych,
- przeciążania panelu,
- rozbudowy przed stabilnym MVP.
