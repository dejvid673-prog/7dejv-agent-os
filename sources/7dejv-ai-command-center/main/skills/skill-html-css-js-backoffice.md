# Skill: HTML CSS JS Back Office

## Cel

Naprawa i projektowanie lekkiego, czytelnego widoku Back Office dla modułów PrestaShop.

## Kiedy używać

Używać, gdy:

- HTML jest rozsypany,
- CSS nie działa,
- JS nie działa,
- przyciski są nieczytelne,
- panel jest za ciężki,
- widok nie pomaga użytkownikowi.

## Dane wejściowe

- aktualny HTML,
- aktualny CSS,
- aktualny JS,
- zrzuty ekranu,
- opis problemu,
- oczekiwany układ.

## Procedura

1. Sprawdź strukturę HTML.
2. Sprawdź klasy CSS.
3. Sprawdź ładowanie plików.
4. Sprawdź błędy JS.
5. Usuń nadmiarowe elementy.
6. Uprość układ.
7. Popraw czytelność.
8. Sprawdź responsywność w panelu.
9. Przygotuj checklistę testów.

## Wynik końcowy

- poprawiony widok,
- lista zmian,
- lista problemów,
- instrukcja testowania,
- rekomendacja dalszych poprawek.

## Zasada

Najpierw naprawić czytelność i działanie MVP. Dopiero później dodawać zaawansowane efekty wizualne.
