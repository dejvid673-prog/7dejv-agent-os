# Skills — biblioteka skilli 7DEJV

Ten folder zawiera skille, czyli gotowe instrukcje pracy dla Codex i AI-workflow.

## Cel folderu

Skille mają zmniejszyć liczbę powtarzanych instrukcji. Zamiast za każdym razem opisywać cały proces, Codex może odwołać się do właściwego skilla.

## Zasada użycia

Skill nie zastępuje myślenia. Skill daje procedurę. Codex ma dobrać skill do celu zadania i dalej pracować etapami.

## Format dobrego skilla

Każdy skill powinien zawierać:

- cel,
- kiedy używać,
- dane wejściowe,
- procedurę,
- wynik końcowy,
- checklistę jakości,
- czego unikać.
