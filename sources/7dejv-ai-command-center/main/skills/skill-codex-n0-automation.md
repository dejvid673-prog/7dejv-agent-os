# Skill: Codex N0 Automation

## Cel

Prowadzenie pracy w trybie automatyzacji N0: etapowo, z audytem, poprawkami i raportem końcowym.

## Kiedy używać

Używać przy większych zadaniach, szczególnie gdy trzeba:

- stworzyć moduł,
- poprawić moduł,
- przeprowadzić audyt,
- uporządkować dokumentację,
- pracować na wielu plikach,
- wykonać analizę i poprawki.

## Dane wejściowe

- cel zadania,
- repozytorium,
- moduł lub obszar pracy,
- wymagania,
- ograniczenia,
- pliki źródłowe.

## Procedura

1. Przeczytaj `README.md`.
2. Przeczytaj `START_HERE.md`.
3. Przeczytaj `AGENTS.md`.
4. Wybierz właściwych agentów.
5. Podziel zadanie na etapy.
6. Wykonaj etap.
7. Zrób audyt etapu.
8. Popraw błędy.
9. Powtórz kontrolę.
10. Zapisz raport końcowy.

## Wynik końcowy

- wykonane zadanie,
- raport z etapów,
- lista zmienionych plików,
- lista błędów i poprawek,
- następne kroki.

## Checklista jakości

- [ ] praca była etapowa,
- [ ] wykonano audyt,
- [ ] poprawiono błędy,
- [ ] zapisano raport,
- [ ] nie dodano zbędnej złożoności,
- [ ] nie pomieszano odpowiedzialności modułów.
