# Prompt graficzny v1.3 — czysta wersja operacyjna

## Cel

Ten dokument opisuje zasady tworzenia promptów graficznych dla projektów 7DEJV.

Ma pomóc w generowaniu spójnych grafik produktowych, reklamowych, marketplace i dokumentacyjnych.

---

## Zastosowanie

Prompt graficzny v1.3 może być używany do:

- etykiet,
- packshotów,
- infografik,
- banerów,
- grafik marketplace,
- plandek reklamowych,
- grafik edukacyjnych,
- grafik technicznych,
- grafik social media,
- grafik koncepcyjnych.

---

## Dane wejściowe

Minimalne dane wejściowe:

- nazwa produktu,
- marka,
- typ produktu,
- zastosowanie,
- grupa docelowa,
- format grafiki,
- styl,
- tło,
- elementy obowiązkowe,
- elementy zakazane,
- teksty na grafice, jeśli są potrzebne.

---

## Dane wyjściowe

Wynik powinien zawierać:

- gotowy prompt graficzny,
- opis kadru,
- styl,
- format,
- tło,
- elementy wizualne,
- teksty na grafice,
- zakazy,
- checklistę jakości.

## Zasady jakości

Grafika powinna być:

- czytelna,
- spójna z marką,
- dopasowana do produktu,
- bez fałszywych danych,
- bez nieistniejących certyfikatów,
- bez losowych norm,
- bez przesadnej ilości tekstu,
- z dobrym kontrastem,
- z bezpiecznymi marginesami.

---

## Zakazy

Nie dodawać:

- fikcyjnych certyfikatów,
- niepotwierdzonych norm,
- fałszywych deklaracji skuteczności,
- danych technicznych, których nie podano,
- logotypów firm trzecich bez zgody,
- tekstu poza marginesami,
- chaosu wizualnego.

---

## Format promptu

```text
Stwórz grafikę typu: [typ grafiki]
Produkt: [nazwa]
Marka: [marka]
Zastosowanie: [zastosowanie]
Format: [format]
Styl: [styl]
Tło: [tło]
Elementy obowiązkowe: [lista]
Tekst na grafice: [teksty]
Czego unikać: [zakazy]
Wymagania jakościowe: [jakość]
```

---

## Przykład zastosowania dla 7DEJV

```text
Stwórz grafikę produktową premium dla preparatu do oczka wodnego.
Produkt: [nazwa produktu]
Marka: 7DEJV
Zastosowanie: poprawa jakości wody w oczku wodnym
Format: 1:1 oraz 16:9
Styl: nowoczesny, czysty, techniczny, premium
Tło: woda, rośliny wodne, delikatne światło
Elementy: opakowanie produktu, krople wody, efekt czystości
Tekst: krótki nagłówek i 2-3 korzyści
Unikaj: fałszywych certyfikatów, nadmiaru tekstu, nierealnych obietnic
```

## Checklista końcowa

- [ ] grafika ma jasny cel,
- [ ] typ grafiki jest określony,
- [ ] format jest określony,
- [ ] produkt jest widoczny,
- [ ] tekst jest krótki,
- [ ] marginesy są bezpieczne,
- [ ] brak fikcyjnych danych,
- [ ] styl pasuje do marki,
- [ ] grafika nadaje się do sklepu lub marketplace.
