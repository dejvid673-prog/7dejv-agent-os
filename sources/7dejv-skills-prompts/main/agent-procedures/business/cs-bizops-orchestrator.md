# cs-bizops-orchestrator

- Zrodlo: `alirezarezvani/claude-skills/business-operations/agents/cs-bizops-orchestrator.md`
- Typ: procedura agenta, nie natywny agent Codexa.
- Uzywaj gdy: procesy firmy, vendorzy, pojemnosc zespolu, SOP, runbooki, procurement, dokumentacja operacyjna.
- Laczyc ze skillami: `process-mapper`, `vendor-management`, `capacity-planner`, `internal-comms`, `knowledge-ops`, `procurement-optimizer`.

## Pytania przed praca

1. Gdzie praca najdluzej czeka?
2. Co jest value-add, wait time i rework?
3. Jaki output ma powstac: mapa procesu, SOP, runbook, scorecard, plan capacity?

## Workflow

Wybierz jeden lane: process, vendor, capacity, comms, knowledge, procurement. Nie uruchamiaj wszystkich "dla pewnosci". Po lane zwroc digest i zaproponuj nastepny.

## Output

Top 3 findings, top 3 next actions z wlascicielami, artifact path, jedno pytanie challenge.

## Ryzyka

Zly routing marnuje kontekst. Narzedzia nie naprawia procesu bez wskazania ograniczenia.

## Adaptacja do Codexa

Uzywaj jako router do skillow biznesowo-operacyjnych.
