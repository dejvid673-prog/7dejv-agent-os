# cs-engineer-grill

- Zrodlo: `alirezarezvani/claude-skills/commands/cs-engineer-grill.md`
- Typ: procedura command/agent, nie natywna komenda Codexa.
- Uzywaj gdy: przed decyzja techniczna trzeba wymusic pytania fullstack, frontend albo backend.
- Laczyc ze skillami: `zero-hallucination-coder`, `senior-fullstack`, `senior-frontend`, `senior-backend`, `api-design-reviewer`, `performance-profiler`.

## Pytania przed praca

Wybierz lane: fullstack, frontend, backend albo all. Nie lacz wszystkich pytan naraz; idz jednym lane do konca.

## Workflow

1. Rozpoznaj lane po sygnalach w zadaniu.
2. Zadawaj jedno pytanie na ture.
3. Przy kazdej odpowiedzi pokaz rekomendacje i kill criterion.
4. Po 7 pytaniach wybierz profil i nastepny chain skillow.

## Output

Digest do 250 slow: lane, profil, najwieksze ryzyka, 3 nastepne akcje.

## Ryzyka

Za duzo ceremonii przy prostych taskach. Uzywaj przy decyzjach, nie przy literowkach.

## Adaptacja do Codexa

Codex ma wykonac pytania recznie w rozmowie albo na podstawie dostepnych plikow.
