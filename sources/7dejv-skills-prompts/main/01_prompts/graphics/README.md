# graphics — prompty graficzne

## Cel

Prompty do grafik produktowych, etykiet, banerów, plandek, mockupów, kontroli jakości tekstów i dokumentacji wizualnej.

## Zastosowania

- grafiki produktowe,
- etykiety G1/G2,
- packshoty,
- grafiki marketplace,
- plandeki,
- banery,
- kontrola czytelności tekstów,
- podział dużych projektów na arkusze.

## Twarda zasada jakości

Nie tworzyć jednej wielkiej planszy z drobnym tekstem.

Duże grafiki z tekstem dzielić na osobne arkusze, a tekst traktować jako warstwę wymagającą kontroli czytelności.
