# codex — prompty do Codex

## Cel

Prompty do pracy z Codex przy repozytoriach, audytach, strukturach plików, dokumentacji i zadaniach technicznych.

## Zastosowania

- audyt repozytorium,
- analiza błędów,
- przygotowanie planu bez wykonywania zmian,
- migracja dokumentacji,
- kontrola jakości kodu,
- przygotowanie raportu końcowego.

## Twarda zasada

Przy zadaniach technicznych Codex najpierw ma badać i raportować, a dopiero potem wykonywać zmiany.

Nie używać promptów, które każą od razu przepisywać moduł lub usuwać pliki bez audytu.
