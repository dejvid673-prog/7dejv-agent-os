# prestashop — prompty PrestaShop

## Cel

Prompty wspierające pracę AI przy PrestaShop.

Ten katalog nie jest źródłem prawdy dla kodu ani dokumentacji technicznej sklepu. Źródłem prawdy dla PrestaShop jest `7dejv-prestashop`.

## Zastosowania

- audyt błędów PrestaShop,
- analiza modułów,
- przygotowanie checklist testowych,
- przygotowanie promptów dla Codex,
- porównanie rozwiązań,
- dokumentacja procedur AI.

## Obecne ograniczenie

Implementacja modułów PrestaShop jest wstrzymana. Prompty w tym katalogu nie powinny nakazywać tworzenia nowych wersji modułów bez audytu i decyzji.
