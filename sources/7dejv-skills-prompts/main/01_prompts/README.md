# 01_prompts — biblioteka promptów

## Cel

Katalog przechowuje prompty używane w pracy 7DEJV.

Prompty mają być uporządkowane według zastosowania, a nie wrzucane luzem.

## Kategorie

- `codex/` — prompty do pracy z Codex i repozytoriami.
- `research/` — prompty do badań i analiz.
- `prestashop/` — prompty dotyczące PrestaShop, ale tylko jako instrukcje pracy AI; dokumentacja techniczna sklepu trafia do `7dejv-prestashop`.
- `graphics/` — prompty do grafik, etykiet, banerów, plandek i kontroli jakości tekstów.
- `products/` — prompty do opisów produktów, namingów, SEO i marketplace.

## Zasada

Każdy ważny prompt powinien mieć:

- nazwę,
- cel,
- zastosowanie,
- wersję,
- status,
- datę ostatniego testu,
- treść promptu gotową do kopiowania.

## Statusy

- `roboczy`
- `do testu`
- `przetestowany`
- `do poprawy`
- `archiwalny`
