# N0 — workflow automatyzacji etapowej

## Cel

Workflow N0 służy do prowadzenia AI przez zadanie etapami, z kontrolą jakości po każdym ważnym kroku.

## Etapy

1. Rozpoznanie zadania.
2. Ustalenie celu.
3. Sprawdzenie danych wejściowych.
4. Plan pracy.
5. Wykonanie pierwszego etapu.
6. Audyt wyniku.
7. Poprawki.
8. Kolejny etap.
9. Raport końcowy.

## Zasada

Nie kończyć pracy po pierwszym szkicu. Wynik ma przejść audyt i poprawki.
