# 04_workflows — workflow pracy AI

## Cel

Katalog przechowuje procedury pracy etapowej z AI.

## Główne workflow

- N0 — tryb automatyzacji etapowej,
- audyt trzykrotny,
- test promptu,
- test skilla,
- migracja dokumentacji,
- raport końcowy.

## Zasada

Workflow ma prowadzić od rozpoznania do raportu końcowego, nie od razu do chaotycznego wykonania.

Minimalny cykl:

1. rozpoznanie,
2. plan,
3. wykonanie,
4. audyt,
5. poprawki,
6. test,
7. raport.
