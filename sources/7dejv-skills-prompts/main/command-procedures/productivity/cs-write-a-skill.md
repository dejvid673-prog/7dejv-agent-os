# cs-write-a-skill

- Zrodlo: `alirezarezvani/claude-skills/docs/commands/cs-write-a-skill.md` i systemowy `skill-creator`.
- Oryginalny sens: tworzenie nowego skilla.
- Natywne w Codex: nie jako command; `skill-creator` jest natywnym skillem.
- Wymaga adaptacji: tak.
- Skille: `skill-creator`, `skill-security-auditor`, `code-reviewer`.

## Procedura

1. Ustal trigger i konkretne przyklady uzycia.
2. Utworz `SKILL.md` z `name` i `description`.
3. Trzymaj body krotko, szczegoly w references.
4. Zweryfikuj frontmatter i sciezki.

## Przyklad 7dejv

`Napisz nowy skill dla audytu kosztow wysylek, ale najpierw zaprojektuj trigger i output.`
