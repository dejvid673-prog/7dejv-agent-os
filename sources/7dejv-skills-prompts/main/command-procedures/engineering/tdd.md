# tdd

- Zrodlo: `alirezarezvani/claude-skills/commands/tdd.md`
- Oryginalny sens: red-green-refactor, testy przed implementacja.
- Natywne w Codex: nie jako command.
- Wymaga adaptacji: tak.
- Skille: `tdd-guide`, `api-test-suite-builder`, `focused-fix`, `code-reviewer`.

## Procedura

1. Napisz oczekiwane zachowanie.
2. Dodaj failing test albo checklist reprodukcji.
3. Implementuj minimalnie.
4. Uruchom test.
5. Refactor tylko po green.

## Przyklad 7dejv

`Zbuduj testy dla naliczania kosztow wysylki przed zmiana algorytmu.`
