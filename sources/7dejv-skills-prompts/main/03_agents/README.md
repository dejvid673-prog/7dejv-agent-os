# 03_agents — instrukcje agentów

## Cel

Katalog przechowuje instrukcje dla agentów AI używanych w systemie 7DEJV.

## Typy agentów

- agent Codex,
- agent audytor,
- agent badawczy,
- agent graficzny,
- agent PrestaShop,
- agent jakości.

## Zasada

Agent ma mieć jasno opisane:

- rolę,
- zakres odpowiedzialności,
- czego nie wolno mu robić,
- wymagany raport,
- kryteria zakończenia pracy.

Agent nie powinien samowolnie zmieniać zakresu zadania.
