# 7DEJV Composition Evidence Skill

Classify evidence as `A` official technical document, `B` label, `C` credible distributor, `D` sales description or `E` hypothesis.

## Steps
1. Search supplied documents and approved sources.
2. Record every ingredient claim with source and confidence.
3. Separate confirmed data, probable data and unknowns.
4. Identify contradictions and questions for a laboratory.

## Output
Return ingredient, function, evidence class, source, confidence, risk and missing data.

## Limits
Do not create a production formula. Evidence class `E` cannot be used for production, dosage, labels or sales claims.
