# 7DEJV Product Copy Skill

## Steps
1. Accept only approved fields.
2. Build a clear description: problem, function, benefits, use, limitations, storage and FAQ.
3. Mark every claim that lacks evidence.
4. Produce channel variants without changing technical meaning.
5. Return a claim-source map.

## Output
Return PrestaShop copy, marketplace copy, FAQ, short graphic messages, missing fields and status `PASS` or `HOLD`.

## Limits
Do not add medical, absolute, guaranteed or unsupported safety claims. Do not publish content.
