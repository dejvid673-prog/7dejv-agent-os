# quality-control — skille kontroli jakości

## Cel

Skille do audytu, kontroli jakości, wykrywania błędów, poprawiania wyników i tworzenia raportów.

## Zastosowania

- audyt promptu,
- audyt skilla,
- audyt grafiki,
- audyt dokumentacji,
- kontrola duplikatów,
- wykrywanie niespójności,
- raport końcowy.

## Zasada

Kontrola jakości ma być krytyczna, konkretna i praktyczna. Nie wystarczy napisać, że coś jest dobre — trzeba wskazać błędy, ryzyka i poprawki.
