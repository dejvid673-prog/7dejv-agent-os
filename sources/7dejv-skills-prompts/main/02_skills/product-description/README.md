# product-description — skille opisów produktów

## Cel

Skille do tworzenia i kontroli opisów produktowych, opisów marketplace, SEO i języka sprzedażowego.

## Zastosowania

- opis główny,
- opis skrócony,
- opis Allegro,
- opis Erli,
- SEO,
- nazwy produktów,
- język korzyści,
- dopasowanie tekstów do problemu klienta.

## Zasada

Teksty produktowe mają być praktyczne, sprzedażowe i zrozumiałe. Nie pisać książek, jeżeli klient potrzebuje krótkiej decyzji zakupowej.
