# prestashop — skille PrestaShop

## Cel

Skille wspierające pracę przy PrestaShop, ale bez bycia źródłem kodu sklepu.

## Zastosowania

- audyt błędów,
- analiza modułów,
- checklista testów,
- raport z pracy Codex,
- dokumentacja techniczna,
- kontrola zgodności z zasadami bezpieczeństwa.

## Ograniczenie

Implementacja modułów jest obecnie wstrzymana. Skille PrestaShop mają pomagać w analizie i porządkowaniu, nie w pchaniu nowych wersji modułów bez decyzji.
