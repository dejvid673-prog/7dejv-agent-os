# research — skille badawcze

## Cel

Skille do badań rynku, produktów, laboratoriów, konkurencji i źródeł.

## Zastosowania

- budowa raportów badawczych,
- analiza konkurencji,
- tworzenie baz produktów,
- badanie laboratoriów,
- weryfikacja źródeł,
- odróżnianie faktów od hipotez.

## Zasada

Wynik badania musi zawierać źródła, wnioski praktyczne, ryzyka i listę dalszych pytań.
