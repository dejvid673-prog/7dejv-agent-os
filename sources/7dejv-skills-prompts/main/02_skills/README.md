# 02_skills — biblioteka skilli

## Cel

Katalog przechowuje skille i instrukcje skilli używane w systemie 7DEJV.

## Kategorie

- `graphics/` — skille graficzne i DTP.
- `prestashop/` — skille wspierające audyt i dokumentację PrestaShop.
- `research/` — skille badawcze.
- `product-description/` — skille opisów produktów, marketplace i SEO.
- `quality-control/` — skille kontroli jakości, audytu i poprawiania wyników.

## Zasada

Skill nie jest gotowy po pierwszym napisaniu.

Minimalny cykl:

1. wersja robocza,
2. test,
3. audyt,
4. poprawki,
5. ponowny test,
6. zapis wersji.
