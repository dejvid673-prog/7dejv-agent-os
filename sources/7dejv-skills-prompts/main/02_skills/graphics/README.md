# graphics — skille graficzne

## Cel

Skille do pracy nad grafikami produktowymi, etykietami, banerami, plandekami, mockupami i dokumentacją techniczną z tekstem.

## Typowe skille

- workflow grafik produktowych,
- builder etykiet,
- packshot/mockup,
- kontrola tekstu na grafice,
- podział dużych plansz na arkusze,
- audyt czytelności.

## Zasada

Grafika z dużą ilością tekstu musi być dzielona na arkusze. Czytelność tekstu jest ważniejsza niż efektowność planszy.
