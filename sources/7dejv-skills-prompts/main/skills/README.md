## Zasada użycia

- `S000` — użyj standardu budowy skilli.
- `S000 mini` — użyj krótkiej listy kontrolnej.
- `S000 audyt SXXX` — oceń wskazany skill.
- `S000 popraw SXXX` — popraw wskazany skill.
- `S000 agent` — zaprojektuj agenta używającego skilli.
- `S000 workflow` — zaprojektuj workflow dla zadania.
- `S001+` — użyj S001 wraz z zalecanymi skillami pomocniczymi.

## Standard nazewnictwa plików

```text
SXXX_nazwa_skilla_vX.X.md
```

Przykład:

```text
S000_standard_budowy_skilli_v1.1.md
```

## Najważniejsza zasada

```text
MVP najpierw, PRO później.
```

Skill, agent i workflow mają pomagać działać, nie blokować pracę teorią.
