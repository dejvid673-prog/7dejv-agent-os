# AGENTS

To repo sluzy do utrzymywania agentow, skills i workflow jako jednej bazy centralnej.

## Reguly pracy

1. Najpierw analiza, potem zmiany.
2. Nie tworz rownoleglych wersji tego samego artefaktu bez wyraznego powodu.
3. Przed oznaczeniem czegos jako `duplicate` porownaj tresc i zrodlo.
4. Przed usunieciem czegokolwiek przygotuj liste sciezek i decyzje cleanup.
5. Repo produktowe nie sa source of truth dla wspolnych skills i workflow.

## Role robocze

- `skills-inventory-agent` - wykrywa artefakty i zbiera dowody
- `skills-organizer-agent` - porzadkuje, normalizuje i wyznacza wersje kanoniczne
