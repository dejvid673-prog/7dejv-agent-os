# Normalization Prompt

Status: `canonical`

Using an evidence-backed inventory and the current canonical policies:

1. group artifacts by purpose and contract, not name alone;
2. identify the existing or proposed `canonical` version;
3. classify remaining candidates as `reference`, `duplicate`, `unclear` or `deprecated`;
4. preserve provenance and distinguish archival `sources/**` copies from active duplicates;
5. propose the smallest reversible migration/cleanup paths;
6. list conflicts, missing evidence and decisions required before promotion/deletion;
7. specify registry/documentation changes and validation required after implementation.

Do not delete an artifact unless a canonical replacement, equivalence evidence and absence of an independent archival role are established. Do not create a new variant to avoid resolving an existing conflict.
