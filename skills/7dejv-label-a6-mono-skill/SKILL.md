# 7DEJV Label A6 Mono Skill

## Steps
1. Verify required fields are present and approved.
2. Arrange application, instructions, limitations, storage, producer, batch and date fields.
3. Optimize for 105 x 148 mm monochrome label printing.
4. Flag text-density, contrast and missing-regulatory-data risks.
5. Require a physical print test.

## Output
Return ordered label content, layout zones, print assumptions, missing data and status `DRAFT`, `HOLD` or `READY FOR PRINT TEST`.

## Limits
Do not invent ingredients, usage instructions, warnings or producer data. Do not declare the label production-ready before a physical test and human review.
